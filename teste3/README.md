    1. Acesso

    1.1. Cadastro

Ao abrir a tela principal toque em "cadastre-se";

Preencha todos os campos e acione o botão "CADASTRAR":

Filial Lisalog = Código da filial da Lisa

Usuário (login) = Login de acesso (deve ser o mesmo usado para acessar o
Protheus)

Nome = Nome completo

E-Mail = Qualquer E-mail válido

Senha = Senha de acesso (deve ser a mesma usada para acessar o Protheus)

12. Expedição

Acesse a opção "Expedição" e para iniciar a expedição (embarque) dos
Romaneios informe o CNPJ da Transportadora ou o código do Romaneio e
acione o botão de pesquisa localizado ao lado.

                       Figura 82 - Informando Romaneio para iniciar expedição

Serão listados todos os romaneios fechados da mesma transportadora do
romaneio informado. Caso seja informado o CNPJ da transportadora, serão
listados todos os romaneios fechados dessa transportadora.

Insira todos os romaneios apresentados para a finalização da expedição e
acione o botão FINALIZAR TRANSPORTADORA. Se todos os romaneios estiverem
confirmados, será solicitada a assinatura. Colete a assinatura e acione
o botão ENVIAR para concluir a expedição dos romaneios.

                         Figura 83 - Finalizando expedição de transportadora

Caso haja necessidade de justificar a não expedição de algum Romaneio
pressione a linha do registro desejado, informe a justificativa e
observações.

                       Figura 84 - Justificando a não expedição do Romaneio

Para verificar se todos os Romaneios de um determinado cliente foram
informados para expedição acione o botão VALIDA ROMANEIOS CLIENTE,
selecione o cliente e pressione Ok.

                           Figura 85 - Verificando Romaneios em Aberto
